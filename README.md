📞 Bony Call Greeting

About the Project

Bony Call Greeting is an Android application developed using Java in Android Studio. The application automatically speaks a greeting message when someone receives an incoming phone call.

The main purpose of this application is to make incoming calls more interactive and personalized.

✨ Features

- Automatically detects incoming phone calls.
- Speaks a personalized greeting message.
- Uses Text-to-Speech (TTS) technology.
- Allows users to enable or disable the greeting.
- Repeats the greeting message twice.
- Works throughout the day when enabled.

🛠️ Technologies Used

- Programming Language: Java
- IDE: Android Studio
- Platform: Android
- Technology: Android BroadcastReceiver
- Speech Technology: Text-to-Speech (TTS)

⚙️ How It Works

1. Open the Bony Call Greeting application.

2. Enable the greeting feature.

3. When an incoming call is detected, the application speaks:
   
   "Bony, your phone is calling."

4. The greeting message is repeated twice.

📱 Installation

1. Download the application APK.
2. Install it on your Android phone.
3. Grant the required permissions.
4. Open the application.
5. Enable the greeting feature.
